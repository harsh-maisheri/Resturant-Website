# Restaurant Website

A static restaurant and food website built with HTML and CSS as an academic front-end project.

## Pages

- `Resturant/index.html` — homepage with food and recipe sections
- `Resturant/order.html` — order page layout
- `Resturant/contact.html` — contact page layout
- `Resturant/style.css` — shared homepage styles

## Run locally

Open `Resturant/index.html` in a web browser. No build step is required.

## Technology

- HTML
- CSS

## Notes

This repository contains a front-end demonstration. The order and contact pages are presentation pages; add a server or form service if you want them to submit real orders or messages.
